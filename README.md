# E-Commerce Analytics & Delivery Prediction

A data analytics and machine learning project using the Olist Brazilian e-commerce dataset.

## What the project covers

- E-commerce order and customer analysis
- Sales, seller, product, payment, review, and delivery analysis
- Business KPI calculation using SQL and Pandas
- Delivery-time analysis and late-delivery prediction
- Machine learning model comparison and interpretation
- Interactive analytics dashboard

## Tools

- Python
- Pandas
- NumPy
- SQL
- Scikit-learn
- XGBoost
- SHAP
- Matplotlib
- Streamlit

## Dataset

The project uses the Olist Brazilian E-Commerce Public Dataset. The raw dataset is kept locally and is not committed to the repository.
